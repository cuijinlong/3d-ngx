# 3D-NGX 界面方案（savehmi 风格）

给前端工程师落地用。产品名只用 **3D-NGX**，不要出现 Savior 品牌、Logo 或「拯救」字样。本方案只定界面和交互，不改仓库代码。

色板（沿用 savehmi）：

| 用途 | 色值 |
| --- | --- |
| 主文字 | `#1f2329` |
| 辅助文字 | `#5f6e84` |
| 主色 / 主色悬停 | `#1657e8` / `#2f6bff` |
| 成功 / 运行 | `#19b37d` |
| 危险 / 停止、告警 | `#e5484d` |
| 预警 | `#c9922a` |
| 离线 | `#6B7178` |
| 页面底 / 工作台底 | `#ffffff` / `#edf1f7` |
| 铭牌底 | `rgba(31, 35, 41, 0.88)` |

不懂技术的人打开后，三件事必须一眼成立：**看全貌、看铭牌数据、能启停设备**。

---

## 1. 工作室 / 运行页

### 现在差在哪

对照 savehmi 天骄科技园场内图，和当前 3D-NGX 两张画面（`gb2-editor-after-visual.png`、更近的 `gb2-editor-live-viewport.png`）：

- 机位要么贴得太近（只能看见三四台），要么模型缩在画面中间偏小，都不是「整排总览」。
- 测点和启停挤在左侧长列表里（还把控制面板、屏幕等接口铺成许多行），设备头顶没有铭牌。
- 「移动 / 旋转 / 缩放」出现在顶栏第一排，像在建模，不像在看现场。
- 引导条、大片空白网格抢了画面。

### 目标画面

打开场景后，默认就是**高机位等轴测总览**：九台模块机整排、管廊、泵和电柜一次看清。参考 savehmi 场内图那种俯看（约俯仰 -48°、方位 58° 的感觉），按场景包围盒自动框进视口，四周留一点边，不要从贴脸距离开始。

每台已绑定的设备，头顶有一块深色半透明铭牌，始终朝向屏幕：

- 远看：状态点 + 名称（如「1# 模块机」）。
- 靠近或选中：展开 2～4 个关键测点，例如温度、功率、开度、运行状态。
- 数值来自绑定测点；若是模拟数据，在铭牌或右栏加「演示数据」标记。
- 点铭牌就是选中这台设备。

选中后，启停必须清楚可点：铭牌下方或右侧卡片里放「启动」「停止」两个按钮，不要只靠左侧一行小字「启动 · 停止」。运行中，「启动」为成功色；「停止」为危险描边。未选中时不要在每台设备上堆按钮，避免九台一起开花。

运行页和预览运行：顶栏只留返回、场景名、全屏、视角。不要出现移动 / 旋转 / 缩放。

工作室：这些编辑工具收到「调整」里（或长按），不要顶在第一排。撤销、保存、导入、预览运行可以留，但视觉权重低于启停和视角。

底部只留：演示播放、视角预设（正面 / 等轴测 / 左等轴 / 俯视）。等轴测是默认。

左侧改成「设备」短名单（模块机、泵、电柜），状态点一眼能扫。197 个可连接点、控制面板 / 屏幕等接口，放到次级「可连接」里，给绑定用，不要当作默认首页。

右侧：选中对象后出一张短卡片——名称、位号、状态、测点（名称 / 数值 / 单位 / 绑定）、启动停止。编辑变换不要默认展开。

工作台和视口用浅底（`#ffffff` / `#edf1f7` + 浅网格），不要改回深色视口。

### 给前端的实现要点

- 默认相机：根据场景 AABB 计算「总览」机位，保证整场入画；记住用户上次视角，但首次打开或点「总览」都回到这个机位。
- 铭牌：屏幕空间广告牌，锚在设备包围盒顶面中心再向上偏移；远近两级密度；水平整排时做简单错层或按距离缩小，避免字叠字。
- 铭牌数据：只展示该设备已绑定、且适合总览的测点（优先运行状态、温度、功率、开度）。接口清单仍按 `hmi-scene/1` 动态读取，不要写死某几台。
- 点击选中、再点空白取消；选中设备可在 3D、左侧名单、铭牌之间同步。
- 演示数据和真实绑定要能区分；默认未绑定时测点「绑定」列为未绑定。
- 不要把 Savior 的素材库、AI 建模、出图、评论搬过来。

## 2. 新建场景表单

用一个白底弹窗，主按钮蓝色。字段按现有平台数据模型走，不要另造一套分类。普通人按从上到下填即可，不必先懂套装编号。

建议字段顺序：

1. **场景名称**（必填）
2. **场站**（下拉，用现有场站列表）
3. **视图类型**（下拉，用现有类型）
4. **分项 / 分区 / 用能性质**（按现有数据模型，有则显示，没有的项藏起来，不要空下拉）
5. **上传模型**：只接受 `.glb`，支持拖入。显示文件名和大小。
6. **风格套装**（必选，大卡片，不要只丢技术编号）
7. **设备底座**
8. **天气地点**（仅全景套装出现，必填）

### 风格套装（界面文案）

两张大卡片，单选。卡片标题用中文，编号只作为辅助或给开发落库。

**HUD 套装**  
适合机房、冷热源。一句话：可折叠浮层、管线三态、自适应底座。  
落库：`hvac-hud-v1@1.0.0`。  
选中后：底座默认「自动」（模块机、冷机用钢结构，水泵、冷却塔用混凝土）；也可改成钢结构、混凝土或无。不出现天气地点。发布后带可折叠浮层、管线三态、自动视角、设备只读信息。

**全景套装**  
适合院区全景。一句话：院区昼夜与天气联动。  
落库：`campus-daynight-v1@1.0.0`。  
选中后：底座默认「无」，并必须填写天气地点，否则不能提交。发布后带昼夜和天气、楼栋和空间相关能力。

### 设备底座

四个选项：**自动 / 钢结构 / 混凝土 / 无**。随套装切换默认值，用户仍可改。

主按钮文案用「创建场景」。未选套装、未上传 GLB、或全景套装没填地点时，按钮不可用并在缺项旁提示，不要用一段说明文字撑满弹窗。

---

## 3. 落地顺序

1. 默认总览机位，弱化或收起移动 / 旋转 / 缩放。
2. 设备头顶铭牌 + 选中后的启动 / 停止。
3. 左侧改成设备短名单，接口列表降为次级。
4. 新建场景弹窗：场站与分类、上传 GLB、风格套装、底座、全景地点。

可先对照 `preview/index.html` 里的界面稿实现，再接到真实 PlayCanvas 视口和接口数据。
