工作空间 / 技术架构说明

技术架构与落地建议

原型用于确认页面与交互；生产环境按下方分层实现：React 应用层 + PlayCanvas 渲染层 + GLB 资产层 + ThingsBoard 适配层，场景 Schema 作为版本化数据契约。

React 18 · PlayCanvas · GLB · ThingsBoard
① 应用层 · React 18 + 路由
大屏页面框架顶栏 / 侧栏 / 面板 / 卡片布局
实例路由与钻取overview → building → hall → device，传参与视角还原
组件系统详情面板、趋势图、标签、告警弹窗、指标卡
在线编程壳提示词、代码编辑、diff 审核、版本管理
② 渲染层 · PlayCanvas 引擎
GLB / glTF 加载器模型实例化、节点命名映射、减面与纹理压缩
场景图与相机对象树、视角聚焦 FlyTo、高亮描边、悬停拾取
事件总线click / dblclick / hover / data:update 事件分发
受限 Scene SDKAI 与脚本只允许调用白名单组件 API
③ 资产与契约层 · 版本化 Schema
SceneSchema JSON布局、槽位、节点、组件、事件与绑定占位符
GLB 资产库建筑 / 设备 / 管网构件，节点 ID 与 schema 对应
模板包可复用布局、组件定义与交互脚本引用
版本与 Diff场景 JSON、模型资源、组件版本、绑定配置整体打包
④ 数据适配层 · ThingsBoard Adapter
连接与认证实例地址、JWT / OAuth2 / 受控代理
实体与遥测订阅设备查询、WebSocket 实时订阅、历史数据
绑定映射表GLB 节点 → 设备 ID → 遥测 key → 展示 / 外观规则
告警与质量规则告警映射、在线 / 延迟 / 离线、空值处理

关键数据流

ThingsBoard WS 推送遥测 └─► Adapter 按绑定表映射到 GLB 节点 └─► DataBindingStore 注入组件 / 外观规则 └─► PlayCanvas 刷新材质、标签、动画 └─► React 面板订阅同一 store 渲染数值 用户点击模型 └─► 引擎拾取 entityId → 事件总线 └─► 跳转规则 / 编程动作（面板 · 钻取 · 聚焦 · 趋势）

方案选型备注

3D 渲染可在 PlayCanvas 与其他引擎间替换：当前原型把渲染能力收敛在「渲染层 + 受限 SDK」之后，React 应用层与绑定层不直接依赖具体引擎实现。GLB 作为标准模型格式，既可由 PlayCanvas 加载，也可在后续迁移到其他 WebGL / 引擎时复用资产与 Schema。
