# 3D-NGX 画面图表与卡片方案（草案）

给总调和用户确认用。确认前不改页面代码、不改仓库、不做 git 提交。产品名只用 3D-NGX，主色 `#1657e8`，浅色工业风（savehmi）。

本方案回答：图表和卡片放在 3D 画面周围的哪里、什么时候出现、怎么和选中设备 / 底部抽屉 / 绑定配置配合、运行态和编辑态有何不同。

它守住 2026-11-21 18:18 已确认的布局，不再回到「浏览态 / 运行态右侧用实时检测和历史数据选项卡」：

- 预览 / 浏览模式右侧整栏不出现，不留空栏，画布铺开。
- 只有点「编辑」才出右侧绑定配置，退出编辑后再收起。
- 底部设备状态和动作抽屉在浏览、编辑、运行态都保留。
- 不要把这些图表卡片做成预览右侧栏，也不要把旧遥测栏搬回来。
- 内容必须由解析器和绑定动态生成，不能写死台数、型号、测点名或图表种类。
- 铭牌显隐、启停资格、只绑实时设备等既有约定不变。

文中「模块机 9#」「温度 ℃」等只是天骄科技园.glb 的例子，换对象或换模型就要换成当时读到的内容。

---

## 1. 建议（先说结论）

把原来准备放在右侧「实时检测 / 历史数据」里的内容，改成 **3D 画布内侧的浮动看板**，不是再占一列侧栏，也不加回画布左侧的设备列表。

分两层，都叠在画布上，不挤窄 3D：

1. **对象看板**：点选某台设备后，在画面内侧出现该对象的测点卡片和（有历史时的）曲线卡片。
2. **场景总览**：沿用方案里已有的画布右下「总览」按钮。点开后在画布里展开场景级汇总卡片，跟是否选中无关；不为此保留右侧栏。

指向设备时仍然只出铭牌，不摊开卡片、不升起抽屉。未选中时画面保持干净，只留画布、底部细提手和右下「总览」。

---

## 2. 放在哪里

工作台骨架不变：最左是产品导航（首页 / 工作室 / 运行 / 搜索 / 设备 / 设置），中间是加宽的三维画布，顶栏保留「查找画面对象」。不要把「可连接 / 设备列表 / 模型」加回画布左侧，不要出现移动 / 旋转 / 缩放。

```
┌─ 顶栏：查找画面对象 · 编辑 · … ─────────────────────────┐
│ 最左导航 │                                              │
│          │   3D 画布铺开                                 │
│          │   选中后：对象看板贴在画布右上内侧（浮动）      │
│          │   铭牌仍在设备上方（指向或选中才出现）          │
│          │   编辑态才在最右侧出绑定配置；此时对象看板      │
│          │   改贴画布左上内侧，避开绑定栏                  │
│          │                                              │
│          │   ▬▬ 底部抽屉（点选升起 / 失焦缩回） ▬▬  总览  │
└──────────┴──────────────────────────────────────────────┘
```

**对象看板**贴在画布内边缘，是浮层，不是布局列：

- 浏览 / 运行态（右侧没有绑定栏）：贴在画布 **右上内侧**，宽度大约一张卡片（约 280–360px），高度随内容，不超过画布高度的一半；内容多为可滚动。历史曲线是同一组里最下面的一张卡片，不要再做成「实时检测 / 历史数据」两个选项卡。
- 编辑态（右侧已有绑定配置）：改贴画布 **左上内侧**，或收到底部抽屉上方，避免和右侧绑定栏重叠。不要把图表塞进右侧绑定配置里。
- 不要挡住底部抽屉、右下「总览」按钮，也不要盖住设备头顶的铭牌。卡片多时叠放并提供「更多」，不要在画面四周摊一圈墙。

**场景总览**由右下「总览」按钮打开，在画布内展开（从右下展开，或沿画布上沿一条可收起的总览带）。这不是右侧栏，也不是未选中时默认摊开的卡片墙。底部抽屉升起时仍不要挡住这个按钮（既有约定）。

**铭牌**仍只在对象头顶：名称、运行徽标、已绑遥测。牌上不做图、不放启停。

「编辑」入口放在 **顶栏**（或底部抽屉上沿），不要为了放这个按钮再留右侧栏。

## 3. 什么时候出现

| 交互 | 铭牌 | 底部抽屉 | 对象看板 | 场景总览 |
| --- | --- | --- | --- | --- |
| 未选中、也没开总览 | 不出现 | 缩回，可留细提手 | 不出现 | 不出现 |
| 只指向（还没点选） | 只出该对象铭牌 | 不升起 | 不出现 | 若已打开则保持 |
| 点选对象 | 出该对象铭牌 | 升起 | 有可展示内容才出现 | 若已打开则收起，避免两层叠满 |
| 点空白 / 失焦 | 隐藏 | 缩回 | 收起 | 若未钉住则保持用户刚才的开关状态 |
| 点「总览」 | 不影响 | 不影响 | 若已打开则收起 | 打开或关闭 |

未选中时不要一进页面就围一圈图表。没有看板数据、也没有已绑测点的对象（例如本模型里的三通、弯头，或未绑定的泵）被点选时：抽屉仍升起，但不出模块机那套测点卡和曲线卡；泵 / PLC 仍只用轻量连接状态，可出现在铭牌或抽屉里，不必再做一张空图表。

第一版不做「钉住看板」。失焦后对象看板随抽屉一起收起，画面回到干净状态。

## 4. 和选中设备、底部抽屉、绑定配置怎么配合

三者分工，不要重复做三遍同一件事：

- **铭牌**：认设备、看最简状态和已绑读数。
- **底部抽屉**：做动作（启停）和看该对象状态；未选中时也可带一行由解析器得到的场景摘要（运行数、对象总数、告警等，不能写死 32 或固定 chip 集）。选中无启停资格的对象时，抽屉仍升起并说明不提供启停。
- **对象看板**：看该对象更完整的测点卡片和历史曲线。这是原先右侧两个选项卡要承担的阅读功能，只是改放在画布内侧。
- **右侧绑定配置**：只在编辑态出现，只做目标设备 / 行为 / 看板数据，不做测点阅读选项卡。
- **场景总览**：看整幅画面的汇总卡片，不跟某一台设备绑死。

点选时抽屉和对象看板一起出现；关掉其中一个不必作为第一版能力。绑定仍只写在本地场景文档里，不写回 GLB。对象看板只展示已经绑上、且解析器认为该对象实际拥有的项。

## 5. 运行态和编辑态有何不同

**浏览（工作室预览）和运行态待遇相同：**

- 右侧整栏不出现，画布铺开。
- 有顶栏「编辑」（仅工作室；运行态没有「编辑」，也不能打开绑定配置）。
- 点选后：铭牌 + 底部抽屉 + 对象看板（贴画布右上内侧）。
- 可用右下「总览」。
- 不要把旧遥测栏（含一进来就调演示控制器、写死启动 / 停止或「演示数据」的那套）搬回来，也不要为了告警或测点再留右侧栏。对象级告警可做对象看板里的一张小卡；场景级告警放进总览。

**编辑态：**

- 点顶栏「编辑」后，右侧出现绑定配置；退出后右侧再收起，对象看板回到右上内侧。
- 编辑过程中，对象看板仍可显示当前绑定的现场预览（绑上一个测点，卡片里就应出现它），但位置改到画布左上内侧或抽屉上方，给右侧绑定栏让位。
- 编辑态未选中时，不要先摊开绑定表；对象看板也保持收起。已选但还没定目标设备时，右侧按既有规则列出行为和看板数据（行先空着），对象看板维持空态或「未绑定，暂无测点」，不要先画出假图。

## 6. 卡片里出什么（必须动态生成）

一律由当前画面的解析结果 + 绑定生成，不要写死台数、型号、测点名或图表种类。

- **数值 / 状态卡片**：来自该对象已绑定的看板数据（`devices[].data[]` 对应的时间序列）。名称、单位跟绑定走；缺测点、空值或订阅失败时写「暂无数据」，不要把模型里的样例 `val` 当成现场值。
- **历史曲线卡片**：仅当该对象有可查询历史的已绑测点时出现。当前若已连接平台但还没有可用的历史接口，卡片写「暂无历史数据」，不画假线，也不在已连接时静默改用演示曲线。演示数据只标在顶栏或状态栏，不要把未标明的演示值混在图里。
- **没有 `data` 的对象**（泵、PLC、阀门、管道、三通、弯头、管配件等）：不要套模块机那套温度 / 功率 / 开度图表。阀门若已绑开关状态，可以出状态卡，不出开度百分比（开度是模块机测点，不要搬过来）。
- **场景总览卡片**：运行对象数、对象总数、告警等，全部从当前解析和绑定汇总，不能写死「设备总数 32」或固定图表种类。没有的项就不要画那张卡。
- 卡片再多也要有上限，超出进「更多」，保证 3D 仍是主体。

## 7. 明确不要做的

- 预览 / 浏览 / 运行态再做右侧栏，或留一条空的右栏。
- 把图表卡片做成预览右侧栏，或把旧遥测栏搬回来。
- 把「实时检测 / 历史数据」两个选项卡原样搬到别的侧栏（左栏也不行）。
- 在铭牌上做图或再放启停。
- 加回左侧「可连接 / 设备列表 / 模型」，或加移动 / 旋转 / 缩放。
- 写死台数、型号、测点名、图表种类或状态 chip 集。
- 为虚拟设备出看板；只绑实时设备。
- 用户确认前改页面代码或做 git 提交。
