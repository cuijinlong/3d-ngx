## 2. 两条进入路径

```
单独打开 /3d-ngx/（没有有效平台会话）
        → 同一套登录页
        → 密码换 JWT，看 Authority
              ├─ TENANT_ADMIN   → 先选客户 → 该客户的场景管理
              └─ CUSTOMER_USER  → /3d-ngx/runtime 默认场景（无管理入口）

已经登录的平台点进来（有效会话，同源复用 JWT）
        → 不再出登录页
              ├─ 租户在客户列表点「场景管理」→ /3d-ngx/customers/{id}/scenes
              └─ 若客户从平台进入                → /3d-ngx/runtime 默认场景
```

从平台进来时，链接只带客户和意图，例如 `/3d-ngx/customers/{customerId}/scenes`、`/3d-ngx/runtime`，不带令牌。现在没有可靠的平台登录回跳，过渡期票无效就降到本登录页；这不是本轮必做。

## 3. 租户从登录页或客户列表进去之后

入口仍可加在 ui-ngx 租户客户列表每一行后面，不做到 `workspace/frontend`。同时，租户也可以不经过平台，直接打开 3D-NGX、用同一登录页进入。

租户侧落点：

```
选客户（仅单独打开、地址里还没有客户 id 时）
        →  /3d-ngx/customers/{id}/scenes
                │
                ├─ 卡片网格：名称、场站、分组节点、是否默认（带缩略预览；选客户同样用卡片，不用表格，见场景管理方案第 10 节）
                ├─ 指定默认、新建 / 下线
                ├─ 打开默认场景（预览，右侧不占栏）
                └─ 进入设计（编辑态，右侧出绑定配置，可编排小部件）
```

不要把「场景管理」做成直接打开默认场景。管理页可以很轻，但必须先能看见这个客户有哪些场景、哪一条是默认。需要看客户看到的画面时，再点「打开默认场景」或「预览」。

选客户只调用现有平台客户列表，不要在 3D-NGX 里再做一套客户管理。从平台带着客户 id 点进来时，跳过这一步，直接进该客户的场景管理。

租户在管理页里「以客户视角预览」时，看到的布局应与客户相同（无编辑、无管理），但那是租户预览，不是客户账号自己的数据视野；真正的客户视野仍以该客户账号打开为准。
