## 硬规则：入口页一律用卡片网格

能不用列表就不要用列表，尽量用卡片。这是入口页的硬规则，不是可选项。

- 选客户、场景管理，以及同类清单页，一律用卡片网格，不用表格，不用纯文字列表。
- 场景管理按第 5 节做成带缩略预览的卡片；选客户同样做成卡片（客户名、场景数量或默认场景提示等），不要客户名单表。
- 空态仍用卡片页上的空说明，不要空表（不要再出现一行表头、下面一句空态的表格）。
- 学参考站的是「整屏缩略图 + 名称 + 状态」这类卡片摆放，不是配色。浅色工业风、`#1657e8`、`--ngx-*`。
- 工作台画布四周仍是已定的「左右翼 + 中央主视觉」，小部件编排规则不改。不要把这条入口页规则套去改工作台。

稿图：`customers-cards.jpg`、`scenes-cards.jpg`、`scenes-empty.jpg`。

## 1. 共用壳（选客户、场景管理、设置、失败页都用这一套）

顶栏同一套，从左到右：

1. 横向品牌「3D-NGX」（左侧一根主色竖条，不要竖排「3D / NGX」）。
2. 面包屑。
3. 弹性空白。
4. 「设置」（放在亮色 / 深色旁，退出之前）。
5. 「亮色」「深色」。
6. 「退出」。

主题开关只出现在顶栏，不要再放到侧栏底部。登录页仍按已确认稿，右上可切亮色 / 深色；登录页本身不必加「设置」。

**面包屑：**

- 有客户名时必须写出来，例如「平台演示中心 / 场景管理」。
- 不要只写一个没有名字的「客户」。
- 若确实没有客户名（还没选过，或当前 id 在名单里对不上名字），面包屑应是可点的「选择客户」，不要出现光秃的「客户」。
- 设置页面包屑写「设置」。打开失败页可写「平台演示中心 / 打开失败」；没有客户上下文时，同样用可点的「选择客户」，不要写无名「客户」。

**品牌点击：** Logo / 品牌回选客户，不要指到无名客户。

**返回场景管理的落点（产品规则，路径由前端走）：** 有刚才在管的真实客户，就回到该客户的场景管理；没有上下文，回到选客户。不要设计成、也不要重定向到名单里没有、也没有名字的客户。租户票里的空的或公共 customerId 不算已经选好的客户；还没明确选过客户时，先落到选客户页。从平台带着真实客户 id 点「场景管理」进来的口径不变。

## 2. 新建场景弹窗

「取消」「创建场景」钉在弹窗底部（固定脚），首屏永远可见。中间表单区可滚，不要把按钮滚出去。窗口再高，脚也不随表单一同滚走。

把「创建新拓扑（把上面的范围作为 roots 提交）」改成「创建新拓扑」。下面给一句说明：「用上面选的场站和分组作为这个场景的范围。」不要在现场文案里写 `roots`。

场景名称不要默认填「新建工业场景」。留空，占位符「给这个场景起个名字」，必填。

其它字段（场站、分组、视图类型、使用已有拓扑、上传模型、风格套装、设备底座）可保留现有表单，只是放进可滚动的中段，不要为了腾按钮删掉必要项。稿图：`mocks/ux-20261121/scenes-new-dialog.jpg`。

## 3. 打开失败页

壳与工作台 / 场景管理同一套顶栏，不要旧窄侧栏，不要把主题开关挤在侧栏底。不要用空白画布冒充已打开（现有这一点保留）。

标题仍可为「打开失败」。正文要具体，按原因分条（前端按实际原因挑一条，不要只写「无法打开该场景」）：

- 找不到这个场景
- 这个场景不属于当前客户
- 暂时连不上服务，请稍后重试
- 打开超时，请刷新或返回场景管理
- 原因不明时：打不开这个场景，请返回后重试

按钮：「返回场景管理」（落点见第 1 节，不要回到无名客户）。可加「刷新重试」。

稿图：`mocks/ux-20261121/scene-open-failed.jpg`（示例用「这个场景不属于当前客户」这条）。

## 4. 设置页

设置按已确认方案先留着，但进出和壳要与选客户 / 场景管理同一套顶栏（见第 1 节）。选客户、场景管理顶栏加「设置」入口。

设置页本身：横向「3D-NGX」、面包屑「设置」、亮色 / 深色 / 退出；去掉旧窄侧栏；主题开关只在顶栏。品牌点击回选客户。页内可有「返回选客户」，有当前客户时也可有「返回场景管理」（落点仍按第 1 节）。

表单内容可保留现有后端连接字段（接口地址、账号、密码、连接 / 断开）。开发说明仍可提醒用 `/api`、不要把 localhost 填到这里。不要把口令写进稿图，也不要在错误信息里回显口令。客户运行态仍不提供改平台地址或改绑定的入口（登录与入口方案第 4 节口径不变）。

稿图：`mocks/ux-20261121/settings-shell.jpg`。

## 5. 场景管理与选客户：卡片网格

入口页一律走上面的硬规则，不用表格、不用纯文字列表，也不用图文行回潮成名单。浅色卡、主色 `#1657e8`、走 `--ngx-*`，不要做成参考站那种深色科幻舱，也不要用深色地图封面冒充本产品预览。

**选客户。** 做成卡片网格，不要客户名单表。每张卡至少有：客户名、场景数量或默认场景提示（还没有指定默认时写「还没有指定默认场景」；有默认时写默认场景名）、入口「场景管理」。空态同样是卡片页上的空说明，不要空表。名单数据仍来自平台已有客户，不在这里新建客户。稿图：`mocks/ux-20261121/customers-cards.jpg`。

**场景管理。** 带 16:9 缩略预览的卡片网格。每张卡：

- 16:9 缩略。有预览时，能看出中间三维主画面、四周浅色数值卡 / 趋势图更好。还没预览时，用视口衬底色（`--ngx-color-viewport`，亮色 `#dce3ed`）+ 「暂无预览」，不要用深色科幻封面冒充。
- 场景名。
- 徽标「默认」「未落库·本地草稿」，仅实际有时出现，不要空列表还挂着本地草稿。
- 场站、分组节点、模板版本等次级信息放在卡内，不要丢。
- 操作：打开 / 设为默认等（已是默认的不必再出「设为默认」；进入设计仍可保留）。

顶栏面包屑必须写出客户名，规则见第 1 节。

稿图：

- `mocks/ux-20261121/scenes-empty.jpg`：空态，文案见第 6 节；卡片页上的空说明，不要空表。
- `mocks/ux-20261121/scenes-cards.jpg`：有几条示例场景，含一条默认、一条本地草稿。示例名要标成演示排版，不要冒充已落库。不要做成表格。

画布四周小部件的编排仍以已确认的小部件方案为准，等小部件真正出现在编辑 / 运行画布上再对照摆放。本稿只改场景管理这一层的列表预览，不改工作台编排方案。

## 6. 空态默认场景文案

还没有指定默认时，写「还没有指定默认场景」，不要写「默认场景指针为未落库 / 本地草稿」。

空态主句可保留：「该客户还没有可管理的三维场景，可以新建一个。」（可同时说明这里只列三维场景，普通设备图不会出现。）

真有本地指针时，再标明「未落库 / 本地草稿」，并且列表里必须能看到对应那一行 / 那一卡。不要只有一句指针说明、列表却是空的。

## 7. 中文失败页（热更新 / 运行态崩溃 / 意外错误）和加载超时

给一层中文全局失败页，壳仍是同一套顶栏。不要出现 Unexpected Application Error、Hey developer、英文堆栈。

- 标题：「页面出了点问题」
- 正文：「发生错误，请刷新后再试。」
- 按钮：「刷新」、「回到登录」

稿图：`mocks/ux-20261121/error-boundary.jpg`。

加载超过合理时间（建议 15 秒）要改成失败或空态，并给返回，不要只剩「加载中」。

- 文案：「加载时间有点长，请刷新或返回。」
- 按钮：「刷新」、「返回」（「返回」的落点按第 1 节：有当前客户回该客户场景管理，否则回选客户或上一页，不要回到无名客户。）

稿图：`mocks/ux-20261121/loading-timeout.jpg`。

## 8. 登录卡文案（不必单独稿图）

缺项和错密码都在登录卡内用中文说，不要用整页警报，不要回显口令，也不要只靠浏览器原生「请填写此字段。」

例如：「请填写账号」「账号或密码不正确」。视觉仍按已确认的 `mocks/login.jpg` 浅色毛玻璃登录卡。

## 10. 明确不要做的

- 搬参考站配色、深色科幻舱、深色地图封面，或另起一套产品口径
- 入口页（选客户、场景管理及同类清单页）做成表格或纯文字列表；空态做成空表
- 把产品名写成「3D-NGX 工作室」，或把侧栏「工作室」加回来
- 恢复旧窄侧栏，或把主题开关放回侧栏底部
- 把左侧「可连接 / 设备列表 / 模型」加回来
- 按「已经做坏」去改小部件编排，或在这版工作台稿上加浮动看板卡片
- 空列表仍写「默认场景指针为未落库 / 本地草稿」
- 失败页只写「无法打开该场景」，或把英文开发者堆栈给到现场
- 面包屑只写「客户」，或把 Logo / 返回指到无名客户
- 把口令写进稿图、方案或错误信息
