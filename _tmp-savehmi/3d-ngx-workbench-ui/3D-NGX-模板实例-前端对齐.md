# 3D-NGX 模板与实例：前端侧对齐（草稿）

给平台架构师对齐用。确认前不改代码、不暗自加接口、不 git。布局仍守 18:18。登录仍是已对齐的密码 → JWT。

这是对总调转达的用户 18:30 产品结构、从前端 / 3D-NGX 角度看的口径。完整草案见 `3D-NGX-模板与实例方案.md`。

---

## 1. 模板、实例，和现有场景 / 拓扑 / 场站的关系

不要另造一套和平台拓扑、`SceneDocument` 平行的「场景」模型。

- **模板**：可复用的画面原型。三维那一层就是 **GLB + 未绑定的 HMI 槽位**，外加风格套装。槽位由现有解析器从根节点 `extras.hmi`（本模型为 `hmi-scene/1`）动态读出：可点选对象、行为、看板测点。模板里不写入某个客户的 `deviceId` 或测点键，也不写死台数、型号、图表种类。
- **实例**：同一模板给不同客户各建一份可看的画面。前端建议 **一个实例 = 已有的一条平台拓扑 + 挂在这条拓扑上的绑定**。场站、视图类型、roots、GLB 引用、套装继续用现有拓扑字段，不要再发明一个场景 ID 去和 `topologyId` 抢位置。
- **`SceneDocument`**：仍是前端打开画面后的运行时文档（解析 GLB，再套上该实例的绑定）。它不是平台上的第二份主数据，也不写回 GLB。
- 场站 / 设备分组：实例通过拓扑上的 `siteId` / `roots` 落到场站和范围，不在 3D-NGX 里再维护一棵平行的分组树。

同一份模板可以生成多个客户实例。实例创建时钉住模板版本，第一版不要自动把模板改动推到已上线实例。

## 2. 实例绑定存哪：这是当前 V1 之后的新能力

已定口径不变：当前 V1 绑定只留本地 `SceneDocument`，不回写 GLB，不暗自新增平台持久化接口。登录收口、新建向导、18:18 工作台布局仍按这条做完。

「租户配置、客户只读、换机器也能看到同一幅画面」做不到只靠本机文档。要把绑定（设备、测点、卡片值、3D 动作）存到该实例（这条拓扑）上，由平台按登录身份下发。

前端明确：**这是当前 V1 收口之后的新能力，不要撑进这一轮，也不要把本地 `SceneDocument` 撑成多客户发布库。** 最小怎么存、怎么按租户读写、按客户只读，请平台架构师出方案；3D-NGX 不单方面发明接口。本机 IndexedDB 仍只作为明确失败时的降级，不能看起来像已经按客户发布成功。

## 3. 客户数据权限在前端怎么用（仍只绑实时设备）

前端不另做一份「客户可见表」去绕过平台。继续只绑实时设备，虚拟标志仍看 `additionalInfo.deviceVirtual`。

已经在用的分流要保持：租户设备列表走 `GET /api/tenant/devices`，客户用户走 `GET /api/customer/{customerId}/devices`，再排除虚拟设备，并与场站 / 拓扑范围求交。

前端期望平台再补清（或确认已有）的是：

1. **租户为客户 A 配置时**，目标设备下拉不能用租户全量设备，只能出现 **客户 A 名下、且为实时** 的设备。请提供（或确认租户身份可调用）按 `customerId` 取该客户设备列表的能力。
2. 测点键、命令清单、历史和实时遥测，在「租户替该客户配置」和「客户自己打开实例」两种身份下，都只返回该客户有权访问的数据。
3. 客户打开实例时，只用自己的 JWT 去订阅和拉数；前端不缓存租户配置时看过的全量设备表。
4. 图表和卡片的槽位仍由解析器按 GLB 动态生成；卡片上的值只来自本实例已绑定、且当前身份有权读取的时间序列。没有权限或没有绑定，就空态或「暂无数据」，不用模型样例值冒充现场值，也不画出别的客户的数。

缺的过滤由平台保证，不由前端猜。

## 4. 鉴权怎么分；客户能不能下达 RPC / 启停（未说定，要问用户）

登录协议本轮不变，仍走已对齐的密码 → JWT，不另建 3D 用户库。

- **租户**：选模板、创建 / 下线实例、进入工作室编辑态、做绑定。预览客户观看态时，应能退出编辑，看到和客户相同的布局（右侧整栏不出现，画布铺开，底部抽屉保留）。
- **客户**：只列出并打开属于自己的实例。没有「编辑」，看不到右侧绑定配置，不能改模板或换设备。

「只点进去看」和「GLB 可视化与操作」是否包含客户下达 RPC / 启停，前端**不暗自定**。偏好是：客户默认只看；底部抽屉仍出现（有控制面板和屏幕的对象才有启停位），但只有该客户对该设备确实有操作权限时按钮才可按，否则禁用并说明原因。请和平台侧一并交总调问用户：客户是纯观看，还是被授权后也可以启停、下发已绑定的命令。

布局、工作台视觉仍守既有约定。设备性质双写那条线不挡这次对齐。
