## 3. 谁来拖拽，客户看到什么

| | 租户（编辑态） | 客户（打开自己的实例） |
| --- | --- | --- |

| 启停、下发已绑定命令 | 可以预览 | 要，按 18:42 已拍板口径；仍走底部抽屉，不把启停做到小部件上 |
| 进入编辑、看到右侧绑定配置 | 要 | 不要，也没有「编辑」 |

编排只发生在租户已点「编辑」之后。在编辑态顶栏加一个轻量的「编排」开关（或等价入口）：打开后才能拖拽和从清单里添加小部件；关掉后，点画布仍是选 3D 对象做绑定。不要为了编排再做一个预览右侧栏。

添加小部件时，类型和可绑数据都从当前画面的解析结果和实例绑定来，不要给一份写死的「温度、功率、九台模块机」清单。没有可绑数据时，清单为空或说明暂无可展示的测点，不要用模型样例值冒充现场值。

客户看到的是租户排好的同一套布局，位置、大小、透明度都不可改。没有权限或没有绑定的卡片，显示空态或「暂无数据」，不要画出别的客户的数，也不要为了好看用演示值填满。

模板里可以带一份默认排版（位置、小部件种类、未绑定的槽位），不含某个客户的 `deviceId`。实例创建时钉住这次排版，租户再按该客户权限去绑数据和微调。第一版不要自动把模板上的排版改动推到已上线实例。

## 4. 小部件长什么样（半透明，但不换风格）

小部件是浅色毛玻璃卡片：圆角、淡阴影，背景半透明，3D 场景能透出来。这是为了更醒目、更像大屏，不是另做一套深色科幻玻璃——底部抽屉已经约定用 savehmi 浅色工业风，小部件要跟它一家，不要突然改成深色舱。

租户可调：

- 透明度：见第 11 节。默认 72%，与主题变量 `--ngx-glass-bg` 的透明度一致；可按整屏统一调，也可对单个小部件单独覆盖。只改卡片玻璃底和描边的透明度，文字、数字、图标和曲线仍用全不透明的主题色，避免字发虚。不要透到字读不出来（下限 50%，上限 90%）。
- 毛玻璃模糊沿用 `--ngx-glass-blur`（16px），不跟透明度滑杆绑在一起，也不要为了更透再加大模糊或加上发光。
- 不要霓虹描边、不要紫色渐变、不要大段说明文案

数字、名称、坐标轴必须够清楚。演示数据仍只标在状态栏或卡片上的「演示」标记里，不能和现场值混在一条成功提示里。

小部件种类都登记为可扩展的 `type`，不是写死在页面里的固定套餐（见第 9 节）。本轮先实装：

- **数值卡**：一个已绑测点的当前值、单位、名称
- **趋势图**：一个或一组已绑测点的历史曲线（有历史才出图，没有就空态）
- **汇总卡**：由解析器和本实例可见绑定算出的汇总（例如运行中的台数），不能写死「设备总数 32」
- **选中对象卡**（可选，至多一个）：跟随当前选中的对象，展示该对象已绑测点；未选中时收成轻量空态，不要为此恢复右侧「实时检测 / 历史数据」选项卡

标题也是可配置的一种 `type`，不要把大屏标题写死在页面里；本轮至少在数据里留出这个类型，不必先做成完整自助设计器。以后新增的图表种类、地图，同样登记为新的 `type`，走同一份布局。启停和状态操作仍放底部抽屉，不要做到小部件上。

## 11. 小部件透明度（2026-11-21 23:05，Asia/Shanghai）

### 11.1 怎么调

**整屏默认 + 单个覆盖。** 两种都只要，不要只做其中一种。

- **整屏默认：** 在租户已打开「编排」后，编排工具条（或编排面板）里放一个「透明度」滑杆。它改的是这一屏的默认透明度，所有还没单独调过的小部件一起跟着变。标题、数值卡、趋势图、汇总卡都吃这个默认值。
- **单个覆盖：** 选中某一个小部件后，属性里再出现同一个滑杆。这时只改这一张，覆盖整屏默认。旁边给一个「使用整屏默认」，用来清掉这张的覆盖。
- **谁能调：** 只在租户编辑态、并且打开了「编排」时能调。客户打开自己的实例时，布局只读，看不到滑杆，也不能改透明度。浏览态、未开编排时也不要在画布上露出透明度控件，以免和选 3D 对象抢操作。
- **实时预览：** 拖动滑杆时，画布上立刻看到玻璃更实或更透，不必先保存。写入布局 JSON 的时机与位置、尺寸相同。

不要做「运行态再给客户一个临时透明度」——客户看到的就是租户排好的那一版。

### 11.2 默认值和范围

| 项 | 值 | 说明 |
| --- | --- | --- |
| 默认透明度 | **72%** | 与《3D-NGX-样式主题规范》里 `--ngx-glass-bg` 的 alpha（0.72）一致，亮色、深色都用这个百分比 |
| 可调范围 | **50%–90%** | 低于 50%，字和曲线容易看不清；高于 90%，卡片接近实心底，场景透不出来 |
| 滑杆步长 | 1% | 显示成百分数，例如「72%」 |
| 模糊 | `--ngx-glass-blur`（16px），两边主题相同 | 不随透明度滑杆变化，也不单独再做一套炫光模糊 |

只改变玻璃底和玻璃描边的不透明度。文字、数字、单位、图标、坐标轴和曲线一律走 `--ngx-color-text` / `--ngx-color-muted` 等全不透明色，不要把整张卡（含内容）一起淡出。

切亮色 / 深色时，玻璃的颜色仍跟 `--ngx-glass-bg`、`--ngx-glass-border` 走，**已保存的透明度百分比不变**。深色用深色玻璃，不要在深色主题里再套浅白卡片，也不要因为调低透明度就加上霓虹描边或发光。

### 11.3 怎么存

布局 JSON 里只存百分比（或 0.50–0.90 的小数），不要把某一套主题的 `rgba(...)` 写进模板。

- 整屏默认：例如 `layout.glassOpacity`，缺省或未写就当 0.72。
- 单个覆盖：例如 `widgets[].style.opacity`，有值就覆盖整屏默认，没有就继承。模板只带排版和这个透明度，不含客户数据。

渲染时用主题里玻璃色的 RGB，再套上这条透明度。不要为了透明度新做一套色板，也不要改 `--ngx-glass-bg` 的默认值本身——那 0.72 仍是未编排或未改时的默认外观。

尚无持久化接口时，这条与整份布局 JSON 一起放本地草稿，并标明「未落库 / 本地草稿」。
