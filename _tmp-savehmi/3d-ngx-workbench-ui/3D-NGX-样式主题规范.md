# 3D-NGX 样式主题规范

2026-11-21 21:31（Asia/Shanghai）。用户要求前端支持亮色和深色主题切换，并整理一套标准样式模板，后面统一风格。本稿给前端对照落地，也作为后续登录页、工作台和小部件的用色依据。

## 1. 结论

1. **一套变量，两套色值。** 亮色、深色共用同一组 token 名。页面、登录、工作台、小部件、铭牌、抽屉都只引用变量，不在组件里写死色值。以后加图表、地图、大屏标题，也走这套变量，这样模板在两套主题下都能用。
2. **默认亮色。** 亮色就是已经对齐 savehmi 的浅色工业风，主色 `#1657e8`，文字 `#1f2329` / `#5f6e84`，页面底 / 工作台底 `#ffffff` / `#edf1f7`。深色是同一套工业风的夜间配色，不是另一套产品脸。
3. **只换颜色和阴影，不换尺度。** 字号、行高、间距、圆角、控件高度两边相同，避免切主题时布局跳动。
4. **深色仍然是工业风。** 不要深色科幻舱，不要紫色渐变，不要能源卫士绿，不要旧 3D 页那套青色发光（`#22d3ee`）。主色两边都是 `#1657e8`。
5. **不要和平台壳混用。** 平台 `--gt-*` 主色是 `#174A8E`，3D-NGX 用自己的 `--ngx-*`，不要把两套变量掺在一起。
6. **本轮只切界面，不切三维场景。** 风格套装、GLB 光照、昼夜天气不随 UI 主题自动改。画布四周的界面底和视口衬底跟随主题，模型本身不变。
7. **小部件的玻璃要跟主题走。** 亮色用浅色半透明毛玻璃（已确认，不用深色玻璃）；深色用对应的深色半透明毛玻璃，不要在深色主题里再套一层浅白卡片。

---

## 2. 怎么切换

- 根节点用 `data-theme="light"` 或 `data-theme="dark"`（默认 `light`）。
- 用户选择记在本机 `localStorage`，键名 `ngx-theme`，值 `light` 或 `dark`。没有记过就用亮色，不要偷偷跟系统主题，以免和已确认的浅色稿不一致。
- 开关放在登录页和工作台顶栏，一处切换，全站立刻换。客户运行态也可以切，只影响自己的界面，不改租户编排。
- 和 Ant Design 的 `ConfigProvider` 同步：亮色用默认算法，深色用暗色算法，token 仍映射到下面这组值。

## 5. 和现有方案怎么衔接

- **登录页：** 已确认稿是浅色毛玻璃大屏感。有了深色主题后，登录页也要能切，深色时用深色毛玻璃，不要改成科幻舱。默认仍先出亮色，和已确认稿图一致。
- **工作台：** 浏览态右侧不占栏、编辑态出绑定、底部抽屉保留，这些交互不变。抽屉、顶栏、侧栏都走 token。
- **小部件与模板：** 布局 JSON 里的样式尽量引用 token 名（或语义，如 `surface` / `glass`），不要把某一套主题的十六进制色写进模板。这样以后用模板或对话生成大屏时，换主题不必重排。
- **小部件透明度：** 用户已明确要可调。默认沿用 `--ngx-glass-bg` 的 0.72，范围 50%–90%；只改玻璃底和描边的不透明度，文字和曲线保持全不透明。整屏可设默认，单个小部件可覆盖。布局 JSON 只存这个百分比，不把 `rgba` 写进模板。交互细节见《3D-NGX-画面小部件编排方案》第 11 节。不要另起色板，也不要为了更透改成科幻发光。
- **落点：** 以 `packages/config` 的主题为单一来源，导出 CSS 变量和 Ant Design 主题；页面和组件只引用，不再复制一份色板。

第 2 步做新登录页时就把这套变量和主题切换带上，不要先写死亮色再返工。开关先做在登录页和工作台顶栏。第 3、4 步直接复用，不再另起色板。
